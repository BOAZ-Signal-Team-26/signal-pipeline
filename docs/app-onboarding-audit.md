## 2. 실측 절차 및 기록 규칙 (마감 12월 2일)

- **실측 단위**: 앱 1종 × 상품군 2종(공모펀드 1건 + ELS 1건) = **총 4개 가입 플로우**
- **안전 규칙**: 실제 매수·청약 직전 단계(최종 비밀번호/인증 입력 직전 화면)까지만 진행하고 실거래는 체결하지 않는다.
- **캡처 규칙**: 단계마다 전체 화면을 캡처하고 계좌번호·성명·잔고 등 개인정보는 마스킹한 뒤 `단계번호_앱_상품군_화면명.png`로 정리한다.
- **측정 지표**:
  1. 최종 확인 직전까지 화면 전환 수(탭 수)와 소요 시간(초)
  2. 투자설명서·간이투자설명서 열람 강제 여부(PDF 열기 필수 / 스크롤 끝까지 강제 / 열지 않고 체크 가능)
  3. 일괄 동의 버튼 존재 여부와 개별 항목 설명 노출 여부
  4. 점검표 v0 10항목별 앱 화면 노출 수준(`화면 직접 노출` / `팝업·접힘` / `PDF 내부만` / `확인 불가`)
