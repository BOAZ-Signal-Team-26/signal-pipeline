# 운용사 코드 대조 기록

- 대응표에 없는 운용사 코드 7종(113행) 중 Phase 1 대상은 237 하나(87행). 한화자산운용(213)의 별칭으로 연결
- 나머지 6종(26행)은 보험·증권사·사모 상품이라 Phase 1 범위 밖. 법인에 연결하지 않음

### 금투협 공시 목록의 운용사 코드

- 공시 목록의 `companyCd`는 `A01021` 형식. 표준코드 안 3자리 운용사 코드와 체계가 다름
- `companyCd`에 213·237을 넣어 조회하면 0건
- 공시 목록을 운용사로 거르려면 `A01xxx` 코드를 써야 함

## KR5 체계와 운용사 연결 순서

### 표준코드 자리만으로는 부족한 이유

펀드명에 대응표의 운용사명(약칭 또는 구상호 앞 2글자)이 들어 있는지로 대조함. 대략적인 대조라 일치하지 않는 행이 모두 틀린 것은 아님.

| 체계 | 행 | 대응표에 있는 코드의 행 | 펀드명과 일치 |
|---|---|---|---|
| K55 | 52,449 | 52,336 | 47,489 (약 91%) |
| KR5 | 128,555 | 111,559 | 63,036 (약 57%) |
| KR5 중 이름에 ETF·상장지수 | 498 | 419 | 346 |

- KR5 체계의 운용사 자리는 펀드 설정 당시 운용사로 보임. 합병·상호 변경 뒤에도 코드는 그대로라 현재 운용사와 다를 수 있음(예: 306 코드의 KTB 이름 ETF, 대응표 약칭은 다올)
- KR5 전체에서 대응표에 없는 코드는 67종, 16,996행

### 결정 (10월 4일 PM 승인)

- 운용사 연결 1단계는 공시 목록의 운용사 코드, 2단계는 표준코드 자리 + 대응표, 실패는 `NO_CANDIDATE`. 펀드·ETF 공통([상품·법인 매칭 규칙](../../matching-rules.md) 「운용사 연결 순서」)
- `distributor`에 공시 운용사 코드 칼럼 `kofia_disclosure_company_code` 추가(ERD v2.2 수정 12)
