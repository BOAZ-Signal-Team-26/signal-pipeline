| 물음 | 답 |
|---|---|
| DART 표지 펀드코드가 `srtnCd`에 있는가 | 10건 중 7건. 나머지 3건은 포털 미등록 |
| `srtnCd` 형식이 5자리 영숫자인가 | 그러함. 165,118종 전부 `[A-Z0-9]{5}` |
| `srtnCd`가 조인 키로 유일한가 | 전역으로는 아님. 4,899종(3.0%)이 겹침. CDI 대상 범위에서는 겹침이 거의 없음 |
| `setpDt`를 판매시작일로 쓸 수 있는가 | 결측 0.00%, 더미 5건. 원 판정 「판매시작일 원천」은 대체됨 → `setpDt`는 설정일(`inception_date`) |
| 판매회사 명단 소스는 무엇인가 | 금투협 전자공시. 문자열이 아니라 코드로 붙음. 은행 채널(신한·국민)에서는 ETF 0건, 증권사(삼성증권)에서는 6건 (09-22 정정) |
| 분쟁조정에 판매사명이 남는가 | 남지 않음. 8건 전부 마스킹. 운용사명도 마스킹(09-20). 업종만 남음 |
| 제재공시 금융회사명이 판매사 표에 붙는가 | 붙음. `finInstName`은 실명. 상품은 본문에서도 `㉮펀드`로 마스킹 → 제재는 판매사 단위 신호 |

- 이 기록의 조인 확인은 코드의 형태와 소스 존재 확인이며, 전체 경로의 유일성·커버리지·실행 가능성 보장이 아님

## 조인 키 확인 현황

### 09-09 확정 소스 4종의 조인 키 후보 (출발점)

09-14 컨텍스트 브리프에 기록된 09-09 확정 사항.

| 소스 | 조인 키 후보 | 이후 |
|---|---|---|
| 금융상품통합비교공시 | `fin_prdt_cd` 계열 | 펀드·ETF·ELS 없음. 조인 키로 성립하지 않음 |
| OPEN DART | `rcept_no`(접수번호), `corp_code` | 코드로 확인 |
| ~~공공데이터포털 증권상품시세정보~~ → 공공데이터포털 펀드상품기본정보 (09-20 정정) | ~~`ISU_CD`~~ → `srtnCd`·`asoStdCd`. `ISU_CD`는 KRX에서 받음 | 증권상품시세정보는 이 저장소에서 한 번도 열린 적이 없음. 09-09에 적은 소스가 실제 수집 대상과 다름 |
| 국가법령정보 | `MST`, `JO` | 연결 방식 미결 |

같은 브리프의 09-09 확정 사항 중 이후 바뀐 것:

- 「위험등급은 DART 한 소스에만 있음」 → 대체됨 → 금투협 수시공시 첨부 PDF에도 `투자 위험등급 N등급[명칭]` 표기. DART 표지 + 금투협 첨부를 모두 근거로 쓰되 충돌 시 임의 선택하지 않음([데이터 테이블·ERD 설계](../../data-model.md) 「상품과 법인」)
- 「분쟁조정 결정문(814건 중 금융투자 187건)은 상품명이 전부 마스킹」 → 유지. 판매사명·운용사명까지 마스킹으로 확대 확인(「분쟁조정 마스킹」)

## DART 펀드코드 대조

DART 투자설명서 표지 10건의 펀드코드([09-14 초기 소스 확인](initial-source-checks.md) 「DART 표지 10건 실측」)를 포털 `srtnCd`에서 찾음.

| 결과 | 코드 |
|---|---|
| 존재 | E4675, B2170, E5771, E0136, CY091, AT146, AO119 |
| 없음 | EY758, EZ258, EZ029 |

- 판정: 두 값은 같은 체계. 찾아진 7건 모두 펀드명·표준코드가 정합(예: `E4675` → 신한미국나스닥100인덱스증권자투자신탁, `K55210E46751`)
- 없는 3건은 오류가 아님. DART는 설정 이전부터 공시가 올라오고 포털 코드 등록은 그보다 늦음(팀 09-05 기록: 설정일 대비 6일 지연 2건)
- 이 상태가 PENDING_MASTER. 매칭 실패로 세지 않고 정상 대기로 처리

## srtnCd 비유일

- `srtnCd` = `asoStdCd[6:11]`이 100% 일치(표본 5,000건 전수)
- 독립 코드가 아니라 협회표준코드 12자리 안의 한 토막. 앞 6자리(체계 + 운용사)가 다르면 같은 토막이 나올 수 있음

| 항목 | 값 |
|---|---|
| 고유 `srtnCd` | 165,118종 |
| 2건 이상이 공유하는 코드 | 4,899종 (3.0%) |
| 그중 `asoStdCd`도 다른 것 | 4,899종 전부 (별개 펀드) |
| `basDt`만 다른 스냅숏 중복 | 132종 |

- 예: `20061`이 `KR5104200617`(개인연금 혼합 투자신탁 2호, 1994), `KR5106200615`(한남안정주식투자신탁 3호, 1994), `KR5204200616`(해피드림주식투자신탁20C-1호, 1997) 셋에 걸쳐 있음

| 범위 | 겹침 |
|---|---|
| 2015년 이후 설정 펀드끼리 | 5종 (10행) |
| 「상장지수」 1,435건 안 | 0종 |
| `(asoStdCd 앞 6자리, srtnCd)` 쌍 | 183,648종 중 1종 |

- 09-19 결정: `short_code` 단독 조인 유지. 겹치는 4,899종은 대부분 1990년대 구펀드이고 CDI 대상인 공모 펀드·ETF에서는 사실상 겹치지 않음. 복합키로 바꾸면 얻는 것 없이 조인만 복잡해짐
- 대체됨(09-22) → 조인에 쓰되 UNIQUE가 아님. 다중 후보는 AMBIGUOUS. 현행 [상품·법인 매칭 규칙](../../matching-rules.md) 「코드 매칭」
- 단서: 겹침이 문제가 되면 `(asoStdCd 앞 6자리, srtnCd)` 쌍으로 올림. `asoStdCd`는 상품 `standard_code`에 있어 스키마 변경 불필요
- 미확인: 구펀드가 실제 수집 대상에 들어오는지. 「공모로 한정하되 필터는 적재 단계」 규칙상 원본은 전량 보관하므로 적재 필터가 구펀드를 거르는지 확인 필요
